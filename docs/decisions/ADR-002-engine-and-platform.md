# ADR-002 — Engine and Platform Baseline

Status: **Accepted**

## Decision

Use Godot 4.7.2 stable, GDScript, Compatibility renderer, Web/itch.io primary target, and a 720×1280 portrait logical canvas.

## Why

A locked stable engine reduces Codex/API ambiguity; GDScript keeps the project Godot-native and contributor-friendly; Compatibility supports the Web target.
